# The 8U Practice Book

Sixteen 90-minute practice plans for a **9v9 SBMSA 8U girls' season** — eight weeks, two sessions a week, built for a roster that spans complete beginners to experienced players.

**Live:** https://yshi41.github.io/8u-practice-book/

## Printing

Open the site and press **Ctrl+P**. Each session prints to its own sheet — nav and screen chrome drop out, backgrounds go white. Take the sheets to the field; leave the rest at home.

## The weekly loop

The schedule is unstable by design — a random weekday game will occasionally eat a practice — so the week is built so the session you might lose never carries new material.

- **Sunday → teach.** Lands the day after Saturday's game. Every new concept lives here.
- **Weeknight → sharpen.** Rehearses and applies. Safe to lose.
- **Saturday → play.** Two instructions for the whole match, maximum.

## The season arc

Individual → individual against an opponent → scoring → with a teammate → team shape → winning it back → play.

1. Belonging & ball comfort
2. Dribbling to escape
3. 1v1, both ways
4. Scoring
5. Playing with a friend
6. Making the field big
7. Winning it back
8. Play

## Editing

Everything is one self-contained `index.html` — no build step, no dependencies, no external fonts or CDN. Edit it, commit, push; Pages redeploys in about a minute.

## Assumptions

A shared half-field, two pop-up goals, pinnies in two colours, roughly 24 discs, and a ball per girl. Every activity works smaller — adjust grid sizes to the space you actually get.
